A one-sentence pitch for an absurdly specific micro-startup for lazy AI agents: NapSaaS, an agent that attends your Zoom meetings on mute, nods on camera, and bills your boss $5 an hour for looking busy while you nap. The pitch is 137 characters, under the 200-character limit. Running `main.py` writes that single line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output` by default) and echoes it to stdout.

## Run it

```sh
python3 main.py
```
